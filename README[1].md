# Ankita Gupta — Portfolio

Static GitHub Pages portfolio built with HTML, CSS and JavaScript.

## Included
- Ankita Gupta personal information from the supplied CV
- Education section preserved from the original portfolio
- 3 certificate images displayed directly in one row on desktop
- Certificate lightbox preview
- Scroll reveal / sliding animations
- Hover tilt and magnetic interactions
- Animated gradient hero and background aurora effects
- Responsive mobile navigation

## Deploy
Upload all files to the root of a GitHub Pages repository. Keep the `assets` folder together with `index.html`, `style.css`, and `script.js`.
